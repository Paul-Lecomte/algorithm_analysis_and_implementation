## Tasks

The assignment brief specifies four main tasks:

| # | Task |
|---|------|
| 1 | Select and implement a simple algorithm (e.g., bubble sort, binary search) in a programming language of your choice (Python, Java, or C++). |
| 2 | Analyse the algorithm's time complexity (Big-O notation) and explain its efficiency. |
| 3 | Provide a comparison of the algorithm with another algorithm that solves the same problem (e.g., compare bubble sort with quicksort). |
| 4 | Create your code, a graph showing performance (time complexity) for different input sizes, and a 300-word report discussing the algorithm's functionality, efficiency for small vs. large datasets, and a comparison of the two algorithms and their real-world use cases. |

## Planned Approach

1. **Select the algorithms** — choose a primary algorithm and a comparative one from the same problem domain.
2. **Implement** — write clean, well-documented code in the chosen language.
3. **Analyse** — document time complexity using Big-O notation and discuss efficiency.
4. **Benchmark** — generate a graph showing performance across different input sizes.
5. **Write the report** — a 300-word discussion covering functionality, efficiency, and real-world use cases.
